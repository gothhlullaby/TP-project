# Smart Alarm

Smart Alarm — приложение для создания и управления
умными будильниками.

## Технологии

- Python
- FastAPI
- HTML
- CSS
- JavaScript
- Git и GitHub

## Структура проекта

- backend — серверная часть приложения
- frontend — клиентская часть приложения
- tests — автоматизированные тесты
- docs — документация проекта
