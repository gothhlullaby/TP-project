
# Smart Alarm

Smart Alarm — приложение для создания и управления интеллектуальными будильниками.

## Цель проекта

Разработка приложения, позволяющего пользователям создавать, настраивать и управлять будильниками с использованием удобного пользовательского интерфейса.

## Основные возможности

- Регистрация и авторизация пользователей.
- Создание и управление будильниками.
- Настройка времени и параметров срабатывания.
- Включение и отключение будильников.
- Просмотр списка созданных будильников.
